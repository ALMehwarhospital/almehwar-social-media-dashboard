# ALMEHWAR SOCIAL INTELLIGENCE\n\nInternal decision dashboard for AlMehwar Hospital social-media and website performance.\n\n## Decision flow\n\n1. Overview — what happened?\n2. Performance / Platforms / Comparisons — where did it happen and which KPI moved?\n3. Content Intelligence — which content drove the result?\n4. Video Analysis / Creative Lab — what may explain the result?\n5. Findings & Recommendations — what is the evidence-backed diagnosis?\n6. Action Plan — what will the team execute, measure and learn?\n\nWebsite Analytics is maintained as a separate GA4 + Search Console intelligence stream.\n\n## Source of truth\n\nThe canonical business layer is the connected Google Sheet:\n\n- Monthly Overview\n- Content Performance\n- Video Analysis\n- Creative Analysis\n- Recommendations\n- Action Plan\n\nRaw platform tabs and snapshot-history tabs are ingestion/audit layers, not a second business-definition layer.\n\nCurrent-month social data is delivered through the Social Dashboard Apps Script API. The checked-in JSON snapshot is only a fallback cache for the same contract and is explicitly labelled SNAPSHOT if the API cannot be reached.\n\nWebsite live data follows the same rule: API first, snapshot fallback.\n\n## Period states\n\n- CLOSED / HISTORICAL — complete frozen month.\n- LIVE MTD — current month to date from the authoritative API.\n- PARTIAL MTD — incomplete current-period coverage; coverage start must be stated.\n- API PENDING — access is not yet available.\n- SNAPSHOT — cached delivery source; never presented as LIVE API.\n\nJune, July and August 2026 are closed historical periods. September 2026 is current MTD. TikTok September coverage starts on 17 September. LinkedIn current-month API access is pending.\n\n## Metric rules\n\nThe dashboard preserves the difference between 0 and N/A:\n\n- 0 means the source actually reported zero.\n- null / N/A means unavailable, not exposed, pending, not applicable, or not calculable from the approved denominator.\n- Missing metrics are excluded from rankings and peer benchmarks instead of being treated as zero.\n\n### Engagement Rate\n\nCanonical internal rate unit is a ratio from 0–1; the UI converts it to percent.\n\n- Facebook / Instagram: Interactions ÷ Reach\n- TikTok: Interactions ÷ Views\n- YouTube: Interactions ÷ Impressions\n- LinkedIn historical definition: Interactions ÷ Impressions\n\nIf the required denominator is unavailable, Engagement Rate is N/A. No silent denominator substitution is allowed.\n\n## Creative review\n\nCreative Lab never invents review scores from performance. A content item is reviewed only when Creative Analysis contains a real evidence-based review. Pending items remain Pending Review and are excluded from creative averages and quadrants.\n\nThe Sheet contains a Creative Scoring Guide plus visible Data Dictionary and Data Quality & N-A tabs.\n\n## Data delivery architecture\n\nPlatform APIs → Raw Sheets / Snapshot History → Normalization → Canonical Google Sheet layer → Dashboard API contract → Shared client data provider → Dashboard pages.\n\nThe React application has one shared social-data lifecycle so navigation does not create independent competing fetch states.\n\n## Development\n\n- npm ci\n- npm run build\n- npm run lint\n\nProduction GitHub Pages deploys from main. Cleanup/refactor work is validated on a separate branch before merge.\n\n## Data-quality controls\n\n- Data Dictionary: metric definition, denominator/formula, unit, N/A rule, zero rule, canonical source and period rule.\n- Data Quality & N-A: current unavailable/pending areas, evidence, reduction potential, next action and rule until resolved.\n\nUpdate these controls whenever a platform API, permission, reporting definition or coverage window changes.\n
